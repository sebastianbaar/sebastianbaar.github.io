Memories - iOS App

  • iOS
  • SwiftUI
  • AI

"Memories" makes it easy to turn your photos and videos into one single, continuous video — as a visual diary or as a freely curated project.

Two project types

1) Calendar Project (Year / Day)

Save one or multiple clips/photos per calendar year and per day. Perfect for “one moment a day,” travel, baby years, training, building projects, or creative challenges.

2) Free Project (no date)

Collect any media without a date reference and export it as a video — ideal for highlights, events, aftermovies, or social montages.

Quick media selection

  • Preselect directly from the iOS image browser / photo library
  • Photos are automatically converted into video segments (ready for export)

Export & customization

When exporting, you can personalize your video:

  • Set a cover image
  • Add music/audio
  • Show date text labels (for calendar projects)
  • Add multiple clips per day — everything becomes one large, seamless video

Who is Memories for?

  • Anyone who wants to keep a video diary
  • Creators who want to collect clips and export quickly
  • Families, travelers, projects, yearly recaps

Turn moments into a story — with Memories.

SBQuickLook

  • iOS
  • SwiftUI
  • UIKit
  • SPM
  • Swift Package Manager

Quickly preview local and remote files and their content using Apple's QuickLook Framework.

This package provides a wrapper around Apple's QuickLook Framework.

  • Can preview:
    • iWork and Microsoft Office documents
    • Images
    • Live Photos
    • Text files
    • PDFs
    • Audio and video files
    • Augmented reality objects that use the USDZ file format (iOS and iPadOS only)
    • ZIP files
    • ...
  • Can be used with UIKit or SwiftUI.
  • Can be used to preview one or multiple files at once.
  • Can be used with local file URLs or external URLs (it also handels downloading the files).

You can find this package on Swift Package Index and on Swift Package Registry.

Cordova NativeGeocoder Plugin

  • Cordova
  • Ionic
  • Swift
  • Kotlin
  • JavaScript

Cordova plugin for native forward (transform an address into a latitude and longitude) and reverse (transform a latitude and longitude into an address) geocoding using iOS CoreLocation service (Swift) and Android Geocoder class.

No need for creating API keys or querying external APIs!

The Cordova Native Geocoder Plugin for forward and reverse geocoding is also available on Ionic Native - a TypeScript wrapper for Cordova/PhoneGap plugins.
